# Duck Quill brand

The app icon, the mascot and the title logo. Everything here is made for this project.

| File | Use |
|---|---|
| `duck-quill.ico` | Windows icon (16 to 256 px; the close-up head for 48 px and below) |
| `duck-quill-icon-1024.png`, `-512`, `-256`, `-128`, `-64` | App icon, full scene |
| `duck-quill-icon-48.png`, `-32`, `-24`, `-16` | App icon, close-up head for small sizes |
| `duck-quill-icon.svg`, `duck-quill-icon-small.svg` | Sources of the two icons |
| `duck-quill-mascot.svg`, `duck-quill-mascot-1024.png` | The duck on its own, no tile |
| `duck-quill-logo-light.*`, `duck-quill-logo-dark.*` | Title logo: mascot above "Duck Quill" and the tagline ribbon |
| `duck-quill-lockup-light.*`, `duck-quill-lockup-dark.*` | Wide lockup: icon beside the title |

Colours: duck yellow `#FFCC2E`, bill orange `#FF8C22`, beret crimson `#E5265F`, quill lavender `#DCD5FF`,
paint cyan `#46D6FF`, night indigo `#5546D0`, ink navy `#1B1446`.
Type: Lilita One (title, outlined and extruded), Fredoka Bold (tagline). Both SIL Open Font License.
