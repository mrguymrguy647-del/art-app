# Exercises

A short course. Each exercise is a page (what to do, what a good result looks like, which
lessons it practises), a script that is one answer, and that script's picture. Paint your own
answer, then run `quill views` and `quill critique` on it and compare with the page's
numbers. The numbers are warnings, never goals: the page says which findings are expected and
why, and which would mean something is wrong.

| Exercise | Practises | Answer |
|---|---|---|
| [value-study.md](value-study.md): a landscape in three greys | values first, the squint, the focal point | `value-study.json`, `value-study.png` |
| [colour-study.md](colour-study.md): one key, five colours | the key, warm and cool, saving the lights | `colour-study.json`, `colour-study.png` |
| [clouds.md](clouds.md): five kinds of clouds | lit side and shadow side, soft and crisp edges | `clouds.json`, `clouds.png` |
| [water.md](water.md): three kinds of water | reflections, marks that follow the form | `water.json`, `water.png` |
| [character.md](character.md): one character in three poses | symbols, parameters, one outline | `character.json`, `character.png` |

`benchmark.md` (the four fixed subjects and the scoring guide) comes with step 8.
